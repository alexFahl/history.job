# H.J Clipper — Chrome Extension

Capture job postings directly from your browser and save them to your History.job account.

## Install on Chrome

1. Unzip the downloaded `.zip` file into a folder of your choice.
2. Open Chrome and go to `chrome://extensions`.
3. Turn on Developer mode (toggle in the top-right corner).
4. Click "Load unpacked".
5. Select in the unzipped folder, the folder "App" (the one containing the `manifest.json` file).

The H.J Clipper icon will now appear in your Chrome toolbar !

## Usage

1. Click the extension icon.
2. Log in with your History.job credentials.
3. On a job posting page, open the extension, let it capture the details, then save the offer to the profile of your choice.

## Notes

- Pin the extension for quicker access.
- Do not delete the unzipped folder: Chrome needs it as long as the extension is installed.
